## 2. AI-assisted work, disclosed

The following parts of the v2 asset pipeline were AI-assisted:

- **Raster cleanup of the owl source PNG.** Automated background removal, alpha matting, and edge
  cleanup were performed by AI-assisted tooling. The output was reviewed by the human author before
  promotion to the v2 authoritative set.
- **V₄ transform generation.** The NON-NORMATIVE / CRITICAL / METACOGNITIVE state assets were
  generated programmatically from the NORMATIVE source by applying the V₄ transforms (σᵥ, C₂, σₕ).
  These are deterministic geometric operations; the AI assistance was confined to scripting them.
- **Per-state colorisation.** Per-state hue mapping onto the cleaned owl mask was AI-assisted; the
  palette is fixed by the doctrine and the result is verified by `tests/test_v2_assets.py`.
- **Repository scaffolding.** This document, `ASSET-DOCTRINE.md`, `tests/test_v2_assets.py`, and
  `scripts/assemble_owl_tiff.py` were drafted with AI assistance and reviewed by the human author.

## 3. Human-only work, explicit

The following parts of the v2 asset pipeline were performed **manually** by the human author and

## 4. Layered TIFF feasibility statement (honest)

Photoshop / Pixelmator Pro "layered TIFF" is **not** a TIFF feature. The base TIFF spec supports
multi-page TIFFs (multiple IFDs in one file). Photoshop / Pixelmator layered TIFFs additionally
carry a proprietary Adobe Image Resources block (TIFF tag 0x8649) that serialises a PSD layer
stack. Python Pillow can write multi-page TIFFs but **cannot** write PSD-compatible layered TIFFs.

This repository therefore ships:

- **True multi-page TIFFs** generated by `scripts/assemble_owl_tiff.py`. Each per-state TIFF in
  `assets/v2/masters/*-V2-MASTER-1080.tiff` contains three pages: transparent / on white / on dark.
  These are valid baseline TIFFs and open as such in any TIFF reader.
- **Per-state transparent PNGs** in `assets/v2/transparent-1080/` and `assets/v2/transparent-540/`,
  which are the inputs an editorial user would import into Pixelmator Pro to construct a true
  layered TIFF for editorial work.

The repository **does not** claim to produce PSD-compatible layered TIFFs from code. Producing one
requires opening the v2 PNGs in Pixelmator Pro (or Photoshop), assembling the layer stack manually,
and exporting from the host application. This is the documented Pixelmator-required step.
