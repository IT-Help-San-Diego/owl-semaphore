# AGENTS.md — Owl Semaphore

Guidance for AI agents (and humans) working in this repository. Read this before
editing the spec, the math, or the framing.

## What this project is — stated precisely

The Owl Semaphore is **a finite algebra over epistemic states**: the four states
{NORMATIVE, NON-NORMATIVE, CRITICAL, METACOGNITIVE} form the **Klein four-group V₄**,
realized as the symmetry group of a rectangle (identity, two reflections, 180° rotation).
The four states are **operations / transformations on stance**, composed under a single
group operation. See `OWL-SEMAPHORE-SYSTEM.md` §2 and §4A.

This is a **verified** claim. V₄ is forced: two independent commuting involutions
(orientation-of-stance σᵥ, locus-of-audit σₕ) generate exactly four elements, closure
forces the fourth (C₂ = σᵥσₕ), and every element is its own inverse — which selects V₄
over C₄ (the only other order-4 group) and over any non-abelian group.

## What this project is NOT — do not drift into these claims

1. **It is NOT a many-valued logic.** The four elements are *operations*, not *truth-values*.
   There is no entailment relation, no truth tables, no logical connectives (∧, ∨, ¬ over
   the states). Do not describe it as "four-valued logic."

2. **It does NOT extend Boolean algebra / "make Boole quaternary."** That framing is a
   category error (a group of stance-operations is a different object from a logic of
   truth-values) and it invites reviewers to demand machinery the system does not have and
   does not need. Keep the scope where the proof is.

3. **It is NOT a derivative of, or an independent rediscovery of, Belnap–Dunn logic.**
   See the next section for the exact, defensible relationship.

## The Belnap–Dunn relationship (structural rhyme, not kinship) — and why the repo is silent

Four-valued logics such as **Belnap–Dunn / First-Degree Entailment (FDE)** use a
four-element structure (the De Morgan diamond DM₄) that carries a Klein-four (V₄) symmetry
generated by its **two negations** — De Morgan negation and conflation (knowledge-negation).
The Owl Semaphore shares **only that abstract group skeleton (V₄)**. It is the same group,
applied to a different kind of object (stances, not truth-values).

A "structural rhyme" — same group, different domain — is **not** a logical equivalence and
**not** evidence of a shared lineage. Because there are only two groups of order 4, *any*
system built from two independent binary distinctions lands on V₄ automatically; the
coincidence is forced, not deep.

**Decision (current):** the published spec deliberately says **nothing** about Belnap–Dunn.
This is intentional. The repo's credibility rests on claiming exactly what is proven and
stopping there. Adding a Belnap comparison is only worthwhile if it is worded as a *sharp
distinction* ("we share the V₄ skeleton; we are not a logic; here is the boundary"), never as
kinship. Absent a concrete scientific reason to add it, **remain silent** — silence here is
the disciplined, honest default, not an omission.

## A specific math error to never reproduce

The claim **"V₄ is the automorphism group of DM₄"** is **FALSE**. Verified by brute-force
enumeration over all 24 permutations of the four values: Aut(DM₄) **as a De Morgan algebra**
(maps preserving meet, join, and ¬) ≅ **ℤ₂** (order 2 — identity and conflation only). De
Morgan negation ¬ is an *order-reversing anti-automorphism*, not an automorphism. The V₄
that genuinely appears is the group **generated by the two negations {id, ¬, −, ¬−}** acting
on the four values — a symmetry group of the set, not Aut(DM₄).

This false claim appeared only in an external SciSpace cross-reference report; it has never
been in this repository. Keep it that way.

## Epistemic status of the system's claims

- **Proven:** the algebra (closure, involution, commutativity, V₄ structure). See §2.3.
- **Design hypothesis, not yet validated:** that these four states usefully and reliably
  partition how practitioners evaluate real claims. There is no inter-rater reliability
  study, user study, or corpus annotation yet. See `OWL-SEMAPHORE-SYSTEM.md` §12A.2.
- A pre-registered feasibility study (Fleiss' κ, etc.) lives in `studies/irr-pilot-v1/`.
  Run `make test-studies` to verify the analysis toolkit; see that directory's README to run
  the pilot with real raters. A PASS shows the states are *operationally separable* — it does
  NOT validate the *choice* of these four states or their utility vs. alternatives.

## Working principles in this repo

- **Verification over assertion.** A real measurement (computed κ, a brute-force group
  enumeration, `make test`) beats a citation or a confident reading. Back every claim with
  evidence or mark it as a hypothesis.
- **Claim exactly what is proven, and stop.** The system's strength is its restraint.
- **Reality-check big questions back to the truth.** Asking bold questions is encouraged;
  when the evidence says a framing is unreasonable, return to what's defensible.
- `make test` runs the integrity suite + the study-toolkit regression tests; it is wired into
  release pre-flight CI (`.github/workflows/release.yml`). Keep it green.
